# Dead Scribble 🧟

A free, doodle-style two-player zombie survival game, playable directly in a browser without accounts or downloads.

## Play online

After enabling **GitHub Pages** for this repository (**Settings → Pages → Deploy from a branch → main → /(root)**), the public website is:

**https://mangosleepy.github.io/dead-scribble/**

## What is included

- Solo and local same-keyboard two-player co-op, with revives
- 10 waves until dawn, increasing zombie hordes and bosses on waves 5 and 10
- Workshop-only crafting inside a zombie-proof shop
- Bat, spear, pistols, shotguns, SMG, rifle, and a secret laser
- Wooden walls, barbed wire, stone walls, and upgraded sentry turrets
- Material scavenging, supply drops, kill-chain power-ups
- Six random upgrades per wave, with progressively more costly rerolls
- A hide-UI button, pause, and a hidden cheat menu

## Controls

On the game's home screen, click **HOW TO PLAY** for the complete controls.

Player 1: WASD + mouse, E to interact, C to craft (inside shop), B to place, V to change defense, F to heal.

Player 2: arrow keys + Enter to attack, M to interact, comma to place, period to change defense, L to heal.

## Updating

The files are plain HTML, CSS, and JavaScript. Edit `game.js` and commit to `main`. GitHub Pages automatically updates the site once publishing is enabled.

> This is a standalone recreation of the earlier ChatGPT Sites game, not an export of its original private source code.
